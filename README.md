# YourMarionette 다운로드

여러 클라이언트 창에 키·클릭 매크로를 함께 보내는 Windows 도구입니다. (사용하려면 라이선스가 필요합니다)

## 받기

[**Releases**](../../releases/latest) 에서 최신 `YourMarionette.exe` 를 받으세요.
(같은 릴리스의 `YourMarionette_vX.Y.Z.exe` 는 v2.0.3 자동 업데이트용으로, 내용은 같습니다)

## 처음 설치

1. `YourMarionette.exe` 를 원하는 폴더에 둡니다. (설치 과정 없이 바로 실행되는 파일입니다)
2. 실행합니다. 관리자 권한을 묻으면 **예** 를 누르세요.
3. SmartScreen 경고(Windows의 PC 보호)가 나오면 **추가 정보 → 실행** 을 누르세요.
4. 처음 실행하면 라이선스 키를 입력합니다.

설정은 exe 와 같은 폴더의 `settings.json` 에 저장됩니다.

## 업데이트

v2.0.3 부터는 프로그램을 켜면 새 버전이 있는지 확인하고, 바뀐 점을 보여 주며 업데이트할지 묻습니다.

- **업데이트** 를 누르면 새 버전을 받아 확인(서명·해시)한 뒤 실행하고, 지금 창은 닫힙니다.
- 실행 파일 이름은 항상 `YourMarionette.exe` 라서 바로가기·설정이 그대로입니다(v2.0.4 부터).
- v2.0.3 에서 업데이트하면 처음 한 번 `YourMarionette.exe` 로 옮겨 다시 켜집니다. 예전 `YourMarionette_v2.0.3.exe` 파일은 지워도 됩니다.
- v2.0.2 이하를 쓰고 있다면 위 Releases 에서 한 번만 직접 받아 주세요.

## 요구 사항

- Windows 10 / 11 (64비트)
